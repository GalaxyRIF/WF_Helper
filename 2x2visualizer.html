使用说明（实模式）
  • 矩阵元素：直接修改即可，全部视图实时重算（复矩阵模式输入复数，如 1+2i、-i、3）；点击输入框自动全选。
  • 手动输入 λ：回车/失焦生效（复矩阵模式支持 1+2i 格式），与数轴/复平面圆点双向联动。
  • 显示比例：左侧滑动条或输入数值（24–160 px/单位）缩放主图，网格自适应。
  • 红/蓝箭头：特征向量 v₁、v₂，单位长度，在单位圆上旋转（可拉得很近，最小夹角约 1°）；虚线为 Av₁ = λ₁v₁、Av₂ = λ₂v₂ 的验证。
  • 对称锁定：强制 b = c；拖动特征向量时另一个自动正交，矩阵恒对称。
  • 特征值数轴（下方）：拖动红/蓝圆点改变 λ₁、λ₂，矩阵随之更新。
  • 基向量：黄色 eₓ 与青色 eᵧ，同色虚线为其像 Aeₓ、Aeᵧ（即 A 的两列）。
  • 形状变换：青色圆与绿色正方形 [0,1]² 经 A 变换为紫色椭圆与橙色平行四边形（半透明，可整体开关）。
  • λ = x ± yi 为共轭特征值（下方复平面圆点可拖，穿越实轴平滑连续）。
  • w = u + iv 是 λ₁ = x + yi 的特征向量：u = Re w、v = Im w（均单位向量，单位圆上；拖动只改方向且互不影响）。
  • Aw = λw ⟺ Au = x·u − y·v、Av = y·u + x·v——这正是"乘以复数 λ"（旋转-缩放）的体现，验证行即显示这两式。
  • A 在 (u,v) 基下为旋转-缩放 [[x, y],[−y, x]]。
  • λ₁、λ₂ 为两个独立复特征值（下方复平面圆点可拖）。
  • w₁、w₂ 为复特征向量（ℂ²）：复平面中同色实线/虚线箭头 = w 的两个分量；主图中实线/虚线 = 实部 u / 虚部 v 投影（可拖）。
  • 青/橙两个椭圆：A = B + iC（B、C 为实矩阵），对实向量 v 有 A·v = B·v + i·C·v。青色椭圆 = B·v 的轨迹（复像的实部投影），橙色椭圆 = C·v 的轨迹（虚部投影）；复像位于 ℂ² 无法直接画出，两椭圆即其两个"坐标投影"。若 C = 0 橙椭圆收缩为原点。
  • Hermitian 锁定：强制 A = A†（对角实、b = conj(c)）；特征值实数、特征向量自动正交，圆点只能沿实轴拖动。
